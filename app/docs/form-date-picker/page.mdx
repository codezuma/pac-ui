# Form Date Picker

A text input for `YYYY-MM-DD` dates with a calendar popover, bound to a [form](/docs/form)'s `control`. Pasted `dd-mm-yyyy` or `dd/mm/yyyy` values are reformatted automatically.

## Component API

### FormDatePicker

| Prop            | Type            | Description                                   |
| :--------------- | :--------------- | :------------------------------------------------ |
| control           | `Control<T>`      | The `control` object from `useForm()`              |
| name              | `FieldPath<T>`    | The field name, type-checked against `T`           |
| label             | string            | Field label                                        |
| description       | string            | Helper text below the input                        |
| placeholder       | string            | Placeholder text                                    |
| fromDate          | Date              | Earliest selectable date                            |
| toDate            | Date              | Latest selectable date                              |
| inputClassName    | string            | Additional CSS classes on the `<input>`             |
| className         | string            | Additional CSS classes on the field wrapper          |
