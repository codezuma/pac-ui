# Form Switch

A single boolean toggle, switch style, bound to a [form](/docs/form)'s `control`. Renders inside a bordered row with its label and description, useful for settings-style forms.

## Component API

### FormSwitch

| Prop        | Type            | Description                          |
| :----------- | :--------------- | :--------------------------------------- |
| control       | `Control<T>`      | The `control` object from `useForm()`     |
| name          | `FieldPath<T>`    | The field name, type-checked against `T`  |
| label         | string            | Field label                               |
| description   | string            | Helper text below the label                |
| className     | string            | Additional CSS classes on the switch itself |
