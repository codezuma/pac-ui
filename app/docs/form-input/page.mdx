# Form Input

A single-line text input bound to a [form](/docs/form)'s `control`, with a label, description, leading icon, and automatic Zod error display.

## Component API

### FormInput

| Prop           | Type                | Default | Description                                    |
| :------------- | :------------------ | :------ | :---------------------------------------------- |
| control         | `Control<T>`         |         | The `control` object from `useForm()`            |
| name            | `FieldPath<T>`       |         | The field name, type-checked against `T`         |
| label           | string               |         | Field label; a trailing `*` marks it required    |
| description     | string               |         | Helper text below the input                      |
| Icon            | React.ReactNode      |         | Leading icon                                     |
| inputClassName  | string               |         | Additional CSS classes on the `<input>`          |
| className       | string               |         | Additional CSS classes on the field wrapper       |
| ...props        | `React.InputHTMLAttributes<HTMLInputElement>` |  | All other native input props (`type`, `placeholder`, ...) |
