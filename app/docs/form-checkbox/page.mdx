# Form Checkbox

A single boolean toggle, checkbox style, bound to a [form](/docs/form)'s `control`. Pair it with `z.literal(true, { message })` when the box must be checked to submit.

## Component API

### FormCheckbox

| Prop      | Type            | Description                             |
| :-------- | :--------------- | :----------------------------------------- |
| control    | `Control<T>`      | The `control` object from `useForm()`       |
| name       | `FieldPath<T>`    | The field name, type-checked against `T`    |
| label      | string            | Label rendered next to the checkbox          |
| disabled   | boolean           | Disables the checkbox                        |
| className  | string            | Additional CSS classes on the field wrapper   |
