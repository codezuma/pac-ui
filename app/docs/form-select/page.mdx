## Component API

### FormSelect

| Prop              | Type                                       | Default | Description                              |
| :----------------- | :------------------------------------------ | :------ | :------------------------------------------ |
| control             | `Control<T>`                                |         | The `control` object from `useForm()`        |
| name                | `FieldPath<T>`                              |         | The field name, type-checked against `T`     |
| label               | string                                       |         | Field label                                  |
| required            | boolean                                      |         | Shows a destructive-colored asterisk          |
| icon                | React.ReactNode                              |         | Icon rendered next to the label               |
| placeholder         | string                                       |         | Placeholder shown when no option is selected  |
| options             | `{ value: string; label: React.ReactNode }[]` |         | The selectable options                        |
| disabled            | boolean                                      |         | Disables the select                           |
| className           | string                                       |         | Additional CSS classes on the trigger          |
| formItemClassName   | string                                       |         | Additional CSS classes on the field wrapper    |
