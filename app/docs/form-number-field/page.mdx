# Form Number Field

A numeric input with increment/decrement buttons, bound to a [form](/docs/form)'s `control`. Values are coerced to `number` before reaching react-hook-form.

## Component API

### FormNumberField

| Prop            | Type            | Default | Description                                |
| :--------------- | :--------------- | :------ | :---------------------------------------------- |
| control           | `Control<T>`      |         | The `control` object from `useForm()`            |
| name              | `FieldPath<T>`    |         | The field name, type-checked against `T`         |
| label             | string            |         | Field label; a trailing `*` marks it required    |
| description       | string            |         | Helper text below the input                      |
| Icon              | React.ReactNode   |         | Leading icon                                     |
| showButtons       | boolean           | true    | Whether to show the increment/decrement buttons   |
| min               | number            |         | Minimum allowed value                             |
| max               | number            |         | Maximum allowed value                             |
| step              | number \| string  |         | Increment step                                    |
| inputClassName    | string            |         | Additional CSS classes on the number input        |
| className         | string            |         | Additional CSS classes on the field wrapper        |
