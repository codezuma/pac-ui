# Form Array Field

A repeatable list of text inputs, backed by react-hook-form's [`useFieldArray`](https://react-hook-form.com/docs/usefieldarray). Unlike the other field components, it manages its own `Controller`-free subscription internally rather than taking a single `name`/`Controller` pair, since it renders a variable number of inputs.

## Component API

### FormArrayField

| Prop            | Type            | Description                              |
| :--------------- | :--------------- | :-------------------------------------------- |
| control            | `Control<T>`      | The `control` object from `useForm()`          |
| name               | `FieldPath<T>`    | The array field's name, type-checked against `T` |
| label              | string            | Field label                                     |
| description        | string            | Helper text below the list                      |
| placeholder        | string            | Placeholder for each item's input (default: `"Enter item"`) |
| addButtonLabel     | string            | Label for the add-item button (default: `"Add Item"`) |
| className          | string            | Additional CSS classes on the field wrapper       |
