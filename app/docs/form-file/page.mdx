## Component API

### FormFileInput

| Prop        | Type            | Default | Description                                    |
| :----------- | :--------------- | :------ | :-------------------------------------------------- |
| control       | `Control<T>`      |         | The `control` object from `useForm()`                |
| name          | `FieldPath<T>`    |         | The field name, type-checked against `T`             |
| label         | string            |         | Field label                                          |
| description   | string            |         | Helper text below the drop zone                       |
| accept        | string            |         | Accepted file extensions/MIME types                   |
| multiple      | boolean           | false   | Whether more than one file can be selected             |
| className     | string            |         | Additional CSS classes on the field wrapper            |
